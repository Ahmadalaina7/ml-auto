# ML Auto

Website voor autobedrijf ML Auto (Middelburg): publieke bedrijfssite en beveiligd CMS.

Zie **[PROJECT_MAP.md](./PROJECT_MAP.md)** voor de volledige projectinventarisatie: architectuur, datamodel, configuratie, tests, deploy-instructies en de openstaande punten.

## Snel starten

```sh
cp .env.example .env
npm install
npm run dev
```

Admin-omgeving: `/admin` (credentials in `.env`). Review inlog: `admin@mlauto.nl`.
